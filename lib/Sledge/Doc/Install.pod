=head1 NAME

Sledge::Doc::Install - Steps required to set up the Sledge framework

=head1 DESCRIPTION

This document explains the steps required for the initial installation
of Sledge.

=head1 INSTALL SLEDGE

A script that installs the CPAN modules required by the Sledge framework
is provided as cpan_install.pl. Run it as root.

  # ./eg/cpan_install.pl

In addition, mod_perl must be installed.

Next, install the Sledge modules.

  % perl Makefile.PL
  % make
  % make test
  # make install

=head1 SET UP YOUR PROJECT

Create the skeleton modules for your project. Here the project name is
HelloWorld.

Create the skeleton with the wizard tool sledge-setup.
(Run rehash or similar as needed so that your shell picks up the new path.)

  % rehash
  % sledge-setup HelloWorld
  mkdir HelloWorld
  mkdir HelloWorld/Config

  Initial setup for HelloWorld is now finished.

  Remember:

  1) Edit HelloWorld/Config/_common.pm
  2) Make session table.

      Thanks for using Sledge!
                - Sledge development team

=head2 EDIT CONFIG FILE

As the message says, you first need to edit _common.pm.

  $C{TMPL_PATH}     = '/path/to/tmpl_dir';

Specifies the template path.

  $C{DATASOURCE}    = [ 'dbi:mysql:sledge','root', '' ];

Specifies the DSN needed for session management, as an anonymous array.

  $C{COOKIE_NAME}   = 'sledge_sid';
  $C{COOKIE_PATH}   = '/';

Sets the name and path of the session cookie. You can leave these as they are.

  $C{COOKIE_DOMAIN} = undef;

Specifies the cookie domain. If undef, the cookie is issued without a
domain. It is better to set it whenever possible.

By default, Config settings are also read from the file
/etc/HelloWorld-conf.pl. If you write this file as

  $ENV{SLEDGE_CONFIG_NAME} = 'staging';
  1;

then the contents of staging.pm are read as settings *in addition to*
_common.pm. By swapping the contents of /etc/HelloWorld-conf.pl between
the development and production environments, you can switch the
configuration variables.

Instead of using this file, you can also set it in httpd.conf like

  PerlSetEnv SLEDGE_CONFIG_NAME production

=head2 SETUP DATABASE

If you use MySQL for session management (the default), you need a table
for sessions. Create a sessions table in the database specified in the
Config. A sample is in eg/sessions.sql.

  > mysql -uroot
  mysql> create database sledge;
  mysql> use sledge
  mysql> create table sessions (
  id char(32) not null primary key,
  a_session text,
  timestamp timestamp
  );
