=head1 NAME

Sledge::Doc::Hooks - How to use Sledge Hooks

=head1 DESCRIPTION

This document explains how to use hooks in Sledge.

=head1 HOOKS

The hook phases currently available are:

  AFTER_INIT
  BEFORE_DISPATCH
  AFTER_DISPATCH
  AFTER_OUTPUT

=head1 REGISTERING HOOKS

Hooks support class inheritance as well as per-instance hooks. To use
them the way the old after_dispatch was used, register the hook as a
class method.

  package Test::Pages::Bar;

  __PACKAGE__->register_hook(
      AFTER_DISPATCH => sub {
         my $self = shift;
         # ...
      },
  );

You can do it like this. The argument passed to the hook is the Pages
instance at run time. If you register multiple subroutines for one
phase, they are executed in order.

A hook registered here is effective in every class that inherits from
Test::Pages::Bar.

If you want a hook to be effective only for a particular Pages instance,
call it as an object method.

  sub dispatch_login {
      my $self = shift;
      $self->regiter_hook(AFTER_DISPATCH => sub { warn "OK" });
  }

In this case the other dispatch_* methods are not affected. Be careful:
if you call register_hook as a class method from inside dispatch_*,
hooks keep getting pushed one after another.

Since VERSION 0.16 this works as a thin wrapper around the more general
Class::Trigger. See also the Class::Trigger documentation and source
code.
